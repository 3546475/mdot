# 马的加班

> 一款只属于你自己的加班记账本。
> 记下每天加班、请假和上班工时，自动算清加班费、扣款和到手收入。
> **本地优先 · 零数据收集 · 免费无广告。**

「马的加班」是一款 Android 原生加班记录 App。它不问你要账号、不上传你的数据，
所有记录都保存在手机本地（数据库加密），备份也由你自己掌控。

---

## 它能帮你做什么

- 🧾 **记一笔就好**：底部弹层快速记录加班 / 请假 / 上班，选班次、填时长，档位自动判定、金额实时算出。
- 💰 **自动算加班费**：按你设定的底薪或时薪，结合考勤周期自动结算加班费、请假扣款和月收入。
- 🗓️ **日历回看**：每天有没有加班、加了多久一目了然，月小结、今日小结随手可查。
- 📊 **统计图表**：按维度汇总，柱状图、饼图、明细列表，支持自定义时间范围。
- 📤 **导出与分享**：一键导出 CSV 表格、生成工资单长图，也支持从 CSV 导入历史记录。
- ☁️ **备份与恢复**：可备份到自己的 WebDAV 网盘（支持自动备份），或导出备份文件到本地，换机不丢数据。
- 🎨 **随心定制**：多套配色、深浅色模式、Android 12+ 动态取色，底部导航栏也能自由编排。

## 三种工时制度

| 制度 | 适合谁 | 怎么算 |
|---|---|---|
| **标准工时** | 拿底薪、加班给加班费的上班族 | 超 8 小时算加班，平时 1.5 倍、周末 2 倍、法定节假日 3 倍 |
| **小时工** | 按小时计薪 | 纯时薪制，干多少小时算多少钱 |
| **综合工时** | 按考勤周期统筹工时的岗位 | 周期总工时超出标准部分才算加班，法定节假日 3 倍即时结算 |

## 隐私承诺

- **不收集任何数据**：没有账号、没有统计 SDK、没有广告。
- **数据不出手机**：记录保存在本地，数据库经 SQLCipher 加密。
- **备份你说了算**：网盘凭据由系统密钥库加密保管，且永远不会被写进备份文件。

## 下载安装

- 在 [Releases](https://github.com/3546475/mdot/releases) 页面下载最新 APK。
- 系统要求 **Android 10（API 29）及以上**。
- 大多数现代手机选 **arm64（v8a）** 版本即可；不确定就下载 **dual（双架构）** 通用包。

> 安装时如系统提示“未知来源”，按提示允许当前浏览器/文件管理器安装即可。

## 从源码构建

需要 Android Studio 与 JDK 17：

```bash
./gradlew.bat assembleDebug       # 调试包
./gradlew.bat testDebugUnitTest   # 运行单元测试
```

## 技术栈

Kotlin + Jetpack Compose · Material 3 · Hilt · Room（SQLCipher 加密）· DataStore ·
Navigation Compose · OkHttp（手写 S3 SigV4 签名）· kotlinx.serialization
